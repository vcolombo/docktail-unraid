**DockTail**

Watches Docker containers, reads `docktail.*` labels, and exposes matching containers as native Tailscale Services.

DockTail is by marvinvr (https://github.com/marvinvr/docktail); this plugin packages it for Unraid. Both are AGPL-3.0; see LICENSE and SOURCE in /usr/local/emhttp/plugins/docktail.
